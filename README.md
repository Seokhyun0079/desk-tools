업무용 잡툴 모음 (공개).

## Illustrator

| 스크립트 | 설명 |
|----------|------|
| [`illustrator/green-overlay.jsx`](illustrator/green-overlay.jsx) | 선택한 오브젝트와 같은 위치·크기의 녹색 사각형(그린 오버레이)을 생성 |

### 사용법 (green-overlay)

1. Adobe Illustrator에서 문서 열기
2. **파일 → 스크립트 → 기타 스크립트…** 에서 `green-overlay.jsx` 실행  
   (또는 스크립트 폴더에 넣어 메뉴에서 실행)
3. 작성 대상 레이어/그룹 선택 → 대상 오브젝트 선택 → **確認 / 実行**
