# desk-tools

업무용 잡툴 모음 (공개).

## Illustrator

| 스크립트 | 설명 |
|----------|------|
| [`illustrator/green-overlay.jsx`](illustrator/green-overlay.jsx) | 문서 계층에서 복수 오브젝트를 선택하고 같은 위치·크기의 녹색 사각형(그린 오버레이)을 지정 레이어/그룹에 생성 |

### 사용법 (green-overlay)

1. Adobe Illustrator에서 문서 열기
2. **파일 → 스크립트 → 기타 스크립트…** 에서 `green-overlay.jsx` 실행  
   (또는 Illustrator 스크립트 폴더에 넣어 메뉴에서 실행)
3. 위쪽 **作成先** 트리에서 결과를 넣을 레이어/그룹을 펼쳐 선택
4. 아래쪽 **対象オブジェクト** 트리에서 필요한 계층만 펼치고 대상을 클릭해 선택/해제  
   - 트리는 기본적으로 접힌 상태
   - 레이어/그룹 행의 `▶` / `▼` 를 클릭해 접고 펼침
   - 일반 클릭 자체가 누적 복수선택 토글
   - 선택 상태는 `[x]` / `[ ]` 로 표시
   - 이름은 레이어/오브젝트명, 텍스트 내용, 파일명, 심볼명 등을 사용
   - **全選択 / 全解除** 지원
   - 클릭한 오브젝트 위치로 Illustrator 화면 중심 이동
5. **確認 / 実行**을 눌러 선택 대상의 `geometricBounds`와 같은 크기의 녹색 사각형 생성

### 참고

- UI는 일본어입니다.
- 위쪽 트리는 생성 위치로 사용할 레이어/그룹만 표시합니다.
- 아래쪽 트리는 레이어/그룹/오브젝트 계층을 표시하고, 실제 오브젝트 항목을 복수 선택합니다.
- 실행 중 오류가 발생하면 오류 내용과 가능한 경우 줄 번호를 Illustrator 대화상자로 표시합니다.

### 시작 성능 및 실패 기록

- 양쪽 목록은 기본 TreeView 화살표로 접고 펼칩니다. 창을 먼저 표시한 뒤, 본문이 `'ok';`인 BridgeTalk으로 양보하고 계층 조회와 트리 생성은 팔레트 엔진의 완료 콜백에서 이어 갑니다. Illustrator는 BridgeTalk 본문에 `#targetengine`을 적용하지 않으므로 본문에서 팔레트 함수를 호출하지 않습니다. 메시지 전송이 실패하면 같은 단계를 팔레트 엔진에서 마칩니다. 두 트리는 모델을 공유하며, 일반 오브젝트의 하위 컬렉션은 조회하지 않습니다.
- `全選択` 및 `配下を全選択 / 全解除`는 접힌 하위 계층도 포함합니다. 큰 문서에서는 최초 계층 구성에 시간이 필요합니다.
- 로그는 ExtendScript `Folder.userData` 아래 `desk-tools/green-overlay.log`에 저장합니다. 시작 시간(`startup.ready`의 `elapsedMs`), 계층 읽기 시간, 선택·크기 조회·화면 이동·BridgeTalk·생성 실패 단계와 오류·가능한 줄 번호를 기록합니다.
- 1MB 초과 시 직전 로그를 `green-overlay.log.1`로 보관합니다. 문서명이나 오브젝트명은 로그에 넣지 않습니다.
- 오류 대화상자에는 로그 경로 또는 저장 실패 여부가 표시됩니다.
- 원인 및 재발 방지 기록: [`illustrator/failure-log.md`](illustrator/failure-log.md).
- 스크립트 파일은 UTF-8 BOM이다. BOM이 없으면 한글 Illustrator가 파일을 열지 못하고 `읽기에 실패했습니다`만 표시할 수 있다.
- 자동 검증: `node illustrator/tests/green-overlay.test.cjs` (Illustrator/ScriptUI 모의 환경).

- 로딩 중 회전 표시와 처리 개수가 표시되며, `読み込みを中止`로 중단할 수 있습니다. 완료 전 선택·실행은 비활성화됩니다. 중단 후에는 스크립트를 다시 실행하세요. 읽기 메시지 자체가 실패해도 목록 구성은 팔레트 안에서 계속됩니다.
- 한 번에 최대 64개 작업 또는 약 20ms를 처리한 뒤 다음 메시지를 예약합니다. 개별 DOM 호출이나 한 계층의 정렬 자체가 느리면 해당 구간에는 반응이 지연될 수 있습니다.
