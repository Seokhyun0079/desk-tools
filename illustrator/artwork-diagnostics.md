# 要素一覧の診断

1. 調べる文書を開き、メイン版の `green-overlay.jsx` を実行して一覧が完成するまで待ちます。
2. そのウィンドウを開いたまま、ファイル → スクリプト → その他のスクリプトから `artwork-diagnostics.jsx` を実行します。
3. 結果欄をクリックして Ctrl/Cmd+A → Ctrl/Cmd+C でコピーします。

このスクリプトは読み取り専用です。文書名、オブジェクト名、文字内容、画像データ、ファイル名、座標を読み取りません。UUIDや参照は内部の照合だけに使い、結果に出しません。ファイル保存、通信、選択変更、オブジェクト編集は行いません。

結果の `DOCUMENT COLLECTION LENGTHS` は種類別コレクションの長さです。コレクション間で同じ要素が重複するため合算しません。`LOADED TARGET TREE` は現在の下側一覧の表示件数です。`OverlayWindow=absent` の場合はツールを開いて再実行してください。

`PARENT FILTER OBSERVATIONS` は実装と同じ親判定の通過/除外/参照失敗を数えます。階層やコレクションをまたいで繰り返し数えるので、ユニーク要素数とは異なります。`rejected` は正しい下位グループ所属でも増えます。除外数だけで原因を確定しません。

大きい文書では100000回の要素参照、または2048個のコンテナまでで診断を制限します。`sampleLimitReached=true` の場合、標本の種類別件数と親判定は途中までの結果です。例外メッセージは文書情報を含む可能性があるため出しません。

テスト: `node illustrator/tests/artwork-diagnostics.test.cjs`。私有フィールドにアクセスすると失敗するモックを用い、機密の名前・テキスト・パス・座標や例外文を診断結果に出さないこと、件数と親判定、および表示中一覧の比較を検証します。実際のIllustratorでの実行は未確認です。
