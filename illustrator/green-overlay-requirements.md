# Green Overlay 요구사항

이 문서는 Illustrator용 `green-overlay.jsx`의 기능과 UI 요구사항을 정리한 정본이다.

## 기본 전제

- Adobe Illustrator에서 직접 실행하는 스크립트 방식으로 동작한다.
- UI는 전부 일본어로 표시한다.
- Illustrator 문서 안의 레이어, 그룹, 오브젝트 등 모든 계층 구조를 읽어 표시한다.
- 계층은 처음부터 전부 펼쳐놓지 않고, 사용자가 각 항목을 접고 펼칠 수 있어야 한다.

## 전체 UI 구조

패널에는 크게 위쪽 목록과 아래쪽 목록이 있다.

### 위쪽 목록 — 作成先

- 아래쪽에서 선택한 오브젝트들 위에 새로 생성할 요소를 어느 레이어 또는 그룹에 넣을지 지정하는 UI다.
- Illustrator 문서의 레이어 / 그룹 계층을 트리 형태로 표시한다.
- 각 계층은 접기 / 펼치기가 가능해야 한다.
- 사용자는 여기서 하나의 생성 위치를 선택한다.

### 아래쪽 목록 — 対象オブジェクト

- Illustrator 문서 안의 레이어, 그룹, 오브젝트 등 모든 계층을 트리 형태로 표시한다.
- 각 계층은 접기 / 펼치기가 가능해야 한다.
- 실제 생성 대상이 될 오브젝트를 여기서 선택한다.
- 레이어를 펼치면 `このレイヤーを対象にする` 행에서 레이어 전체 범위를 하나의 대상으로 선택할 수 있다. 레이어 이름 행의 기본 개폐 동작은 유지한다.
- 레이어 전체 대상과 `配下を全選択 / 全解除`는 별개다. 전자는 합친 범위에 사각형 하나, 후자는 각 하위 오브젝트에 사각형을 하나씩 만든다.

## 선택 방식

- 복수 선택이 기본 동작이다.
- Ctrl / Cmd / Shift 같은 보조키를 누르지 않는다.
- 일반 클릭 자체가 선택 토글이다.
  - 선택되지 않은 항목 클릭 → 선택 추가
  - 이미 선택된 항목 클릭 → 해당 항목만 선택 해제
- 다른 항목을 클릭해도 기존 선택은 유지된다.
- 선택 상태는 사용자에게 명확하게 보여야 한다.

예시:

- A 클릭 → A 선택
- B 클릭 → A + B 선택
- C 클릭 → A + B + C 선택
- B 다시 클릭 → A + C 선택

## 전체 선택 / 전체 해제

아래쪽 목록에는 다음 버튼이 있어야 한다.

- `全選択`
- `全解除`

동작:

- `全選択` → 기존과 같이 모든 개별 대상 오브젝트를 선택. 레이어 전체 대상을 자동으로 추가하지 않으며, 이미 선택한 레이어 대상은 유지한다.
- `全解除` → 개별 오브젝트와 레이어 전체 대상을 모두 해제

## 오브젝트 클릭 시 Illustrator 화면 이동

- 아래쪽 목록에서 오브젝트를 클릭하면 Illustrator 화면도 해당 오브젝트가 있는 위치로 이동해야 한다.
- 단순히 목록에서 선택 상태만 바뀌는 것이 아니라, 사용자가 Illustrator 캔버스에서 그 오브젝트 위치를 바로 확인할 수 있어야 한다.
- 복수 선택 상태는 유지하면서, 방금 클릭한 오브젝트 위치를 보여준다.

## 실행

사용자가 아래쪽에서 대상 오브젝트들을 선택하고, 위쪽에서 생성 위치를 선택한 뒤 `確認 / 実行` 버튼을 누르면 실행한다.

실행 결과:

- 선택된 각 오브젝트와 같은 위치에 새 요소를 하나씩 생성한다.
- 새 요소의 크기는 원본 오브젝트와 동일하게 맞춘다.
- 현재 단계에서는 새 요소를 단색 초록색으로 생성한다.
- 일반 오브젝트는 기존과 같이 원본의 `visibleBounds`를 우선 사용하고, 취득 오류 시 `geometricBounds`를 사용한다.
- 생성된 요소들은 위쪽 `作成先`에서 지정한 레이어 또는 그룹에 들어간다.

### 레이어 전체 범위

- 레이어에는 자체 크기가 없으므로 하위 레이어·그룹·오브젝트의 표시 경계를 합친 사각형을 사용한다. 떨어진 요소 사이의 빈 공간도 포함한다.
- 숨긴 오브젝트와 숨긴 상위 레이어 아래의 요소, 가이드 패스는 제외한다. 잠긴 요소도 표시 중이면 범위에 포함하며 잠금을 해제하지 않는다.
- 클리핑 그룹은 내용의 경계와 클리핑 패스의 기하 경계를 교차시킨다. 비사각형 마스크는 경계 사각형에 의한 계산이므로 픽셀 단위의 정확한 외곽선 측정은 아니다. 그룹·레이어 자체에 적용된 외관 효과의 확장은 이 합산에 포함하지 않는다.
- 표시 중인 범위가 없는 레이어는 선택할 수 없다. 선택 후 비거나 숨겨진 레이어는 실행 시 생성 실패로 보고하며 다른 선택 요소로 대체하지 않는다.
- 선택 시에는 이미 읽은 계층 모델로 범위를 계산하고 중심으로 화면을 이동한다. 시작 로딩에서는 추가로 크기를 계산하지 않는다.
- 실행 확인 후 모든 선택 레이어의 범위를 실제 문서에서 다시 계산한 다음 생성한다. 같은 실행에서 만든 오버레이가 뒤에 처리할 레이어의 크기를 바꾸지 않도록 범위를 먼저 확정한다.
- 레이어 전체 선택은 도구 안의 생성 대상 선택이다. Illustrator에서 개별 오브젝트를 선택·해제하거나 이동·그룹화하지 않는다.
- 레이어 전체 대상과 그 하위 개별 오브젝트를 함께 선택하면 각각의 대상으로 생성한다. 중복되는 범위의 선택을 자동으로 해제하지 않는다.

## UI 언어

모든 사용자 노출 UI는 일본어로 한다.

예시:

- `作成先`
- `対象オブジェクト`
- `全選択`
- `全解除`
- `確認 / 実行`
- 선택 건수 및 상태 메시지 역시 일본어

## 핵심 UX 원칙

이 도구의 핵심은 다음과 같다.

1. 문서 전체 계층을 트리로 본다.
2. 필요한 부분만 펼친다.
3. 아래쪽에서 일반 클릭만으로 여러 오브젝트를 누적 선택한다.
4. 클릭한 오브젝트 위치를 Illustrator 화면에서 바로 확인한다.
5. 위쪽에서 생성 위치를 정한다.
6. 실행하면 선택된 모든 오브젝트 위에 동일 크기의 초록색 요소를 생성한다.

이 요구사항과 다르게 단일 선택을 기본으로 하거나, Ctrl / Cmd를 요구하거나, 계층을 전부 펼쳐놓거나, 클릭해도 화면 이동이 일어나지 않는 구현은 요구사항 불충족으로 본다.
