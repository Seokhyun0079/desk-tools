# Green Overlay 요구사항

이 문서는 Illustrator용 `green-overlay.jsx`의 기능과 UI 요구사항을 정리한 정본이다.

## 기본 전제

- Adobe Illustrator에서 직접 실행하는 스크립트 방식으로 동작한다.
- UI는 전부 일본어로 표시한다.
- Illustrator 문서 안의 레이어, 그룹, 오브젝트 등 모든 계층 구조를 읽어 표시한다.
- 계층은 처음부터 전부 펼쳐놓지 않고, 사용자가 각 항목을 접고 펼칠 수 있어야 한다.

## 전체 UI 구조

패널에는 크게 위쪽 목록과 아래쪽 목록이 있다.

### 위쪽 목록 — 作成先

- 아래쪽에서 선택한 오브젝트들 위에 새로 생성할 요소를 어느 레이어 또는 그룹에 넣을지 지정하는 UI다.
- Illustrator 문서의 레이어 / 그룹 계층을 트리 형태로 표시한다.
- 각 계층은 접기 / 펼치기가 가능해야 한다.
- 사용자는 여기서 하나의 생성 위치를 선택한다.

### 아래쪽 목록 — 対象オブジェクト

- Illustrator 문서 안의 레이어, 그룹, 오브젝트 등 모든 계층을 트리 형태로 표시한다.
- 각 계층은 접기 / 펼치기가 가능해야 한다.
- 실제 생성 대상이 될 오브젝트를 여기서 선택한다.

## 선택 방식

- 복수 선택이 기본 동작이다.
- Ctrl / Cmd / Shift 같은 보조키를 누르지 않는다.
- 일반 클릭 자체가 선택 토글이다.
  - 선택되지 않은 항목 클릭 → 선택 추가
  - 이미 선택된 항목 클릭 → 해당 항목만 선택 해제
- 다른 항목을 클릭해도 기존 선택은 유지된다.
- 선택 상태는 사용자에게 명확하게 보여야 한다.

예시:

- A 클릭 → A 선택
- B 클릭 → A + B 선택
- C 클릭 → A + B + C 선택
- B 다시 클릭 → A + C 선택

## 전체 선택 / 전체 해제

아래쪽 목록에는 다음 버튼이 있어야 한다.

- `全選択`
- `全解除`

동작:

- `全選択` → 선택 가능한 모든 대상 오브젝트를 선택
- `全解除` → 선택된 모든 대상 오브젝트를 해제

## 오브젝트 클릭 시 Illustrator 화면 이동

- 아래쪽 목록에서 오브젝트를 클릭하면 Illustrator 화면도 해당 오브젝트가 있는 위치로 이동해야 한다.
- 단순히 목록에서 선택 상태만 바뀌는 것이 아니라, 사용자가 Illustrator 캔버스에서 그 오브젝트 위치를 바로 확인할 수 있어야 한다.
- 복수 선택 상태는 유지하면서, 방금 클릭한 오브젝트 위치를 보여준다.

## 실행

사용자가 아래쪽에서 대상 오브젝트들을 선택하고, 위쪽에서 생성 위치를 선택한 뒤 `確認 / 実行` 버튼을 누르면 실행한다.

실행 결과:

- 선택된 각 오브젝트와 같은 위치에 새 요소를 하나씩 생성한다.
- 새 요소의 크기는 원본 오브젝트와 동일하게 맞춘다.
- 현재 단계에서는 새 요소를 단색 초록색으로 생성한다.
- 현재 구현에서는 원본의 `geometricBounds`를 기준으로 같은 크기의 초록색 사각형을 생성한다.
- 생성된 요소들은 위쪽 `作成先`에서 지정한 레이어 또는 그룹에 들어간다.

## UI 언어

모든 사용자 노출 UI는 일본어로 한다.

예시:

- `作成先`
- `対象オブジェクト`
- `全選択`
- `全解除`
- `確認 / 実行`
- 선택 건수 및 상태 메시지 역시 일본어

## 핵심 UX 원칙

이 도구의 핵심은 다음과 같다.

1. 문서 전체 계층을 트리로 본다.
2. 필요한 부분만 펼친다.
3. 아래쪽에서 일반 클릭만으로 여러 오브젝트를 누적 선택한다.
4. 클릭한 오브젝트 위치를 Illustrator 화면에서 바로 확인한다.
5. 위쪽에서 생성 위치를 정한다.
6. 실행하면 선택된 모든 오브젝트 위에 동일 크기의 초록색 요소를 생성한다.

이 요구사항과 다르게 단일 선택을 기본으로 하거나, Ctrl / Cmd를 요구하거나, 계층을 전부 펼쳐놓거나, 클릭해도 화면 이동이 일어나지 않는 구현은 요구사항 불충족으로 본다.
