# Illustrator 툴 실패·수정 기록

## 2026-10-02 — 시작 지연 및 오류 추적 부재

### 확인한 문제

- 접힌 계층도 시작 단계에서 모든 ScriptUI 노드로 생성했다.
- 생성 위치 트리와 대상 트리에서 전체 계층을 각각 읽었다.
- 대상 트리는 자식 유무 확인과 재귀 진입 때 같은 컬렉션을 다시 읽었다.
- 컬렉션 반복문의 길이를 매번 Illustrator DOM에서 조회했다.
- 계층 조회와 개별 오브젝트 생성 오류를 무시해 원인 기록이 남지 않았다.

### 수정

- 최상위 레이어만 초기 표시하고 `onExpand`에서 한 단계씩 노드를 생성한다.
- 두 트리가 같은 계층 모델을 공유하며, 자식 목록을 최초 조회 이후 재사용한다.
- 컨테이너 여부는 종류로 판단하고, 자식 유무 검사를 위한 사전 스캔을 제거한다.
- 전체 선택은 모델의 접힌 계층까지 순회한다. UI가 생성되지 않은 대상도 실행에 포함한다.
- 주요 실패와 시작 소요 시간을 사용자 데이터 폴더의 회전 로그에 남긴다.
- 사각형 생성 후 속성 설정이 실패하면 불완전한 사각형을 제거한다.
- 선택 해제 시 화면 이동을 생략한다.

### 회귀 방지

`node illustrator/tests/green-overlay.test.cjs`로 다음을 검증한다.

- 시작 시 하위 pageItems 조회 0회.
- 두 트리 사이에 자식 조회 캐시 공유.
- 접힌 그룹의 1,000개 대상 전체 선택 및 펼친 후 선택 표시.
- 선택 해제 시 화면 중심 유지.
- 시작 시간 로그 기록.

### 실제 환경 확인 필요

Illustrator와 ScriptUI 실행 환경은 자동 검증에서 모의 처리한다. 실제 실행 시간 개선 폭, 호스트의 펼침 이벤트, 잠금/숨김/삭제된 항목의 DOM 동작은 실제 Illustrator에서 확인해야 한다. 오류가 재발하면 런타임 로그의 해당 단계와 줄 번호를 기준으로 조사한다. 실제 환경 확인 없이 실측 성능이나 완전 해결을 주장하지 않는다.
